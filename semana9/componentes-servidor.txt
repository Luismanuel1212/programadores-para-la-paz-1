Sistema operativo:
Es el software principal del equipo o servidor. Administra los recursos del sistema y permite ejecutar aplicaciones.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para crear servidores y aplicaciones web.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y las respuestas que recibirán los usuarios.

Puerto:
Es un punto de comunicación que permite que el servidor reciba solicitudes. En esta actividad se utiliza el puerto 3000.

Logs:
Son registros de eventos y actividades del servidor. Ayudan a detectar errores y supervisar el funcionamiento del sistema.

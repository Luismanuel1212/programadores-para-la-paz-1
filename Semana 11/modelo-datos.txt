Modelo de datos para una plataforma comunitaria

Entidad: Causa

Campos principales:
- id
- titulo
- descripcion
- fecha

Propósito:
Guardar las causas comunitarias para que los ciudadanos puedan conocerlas y participar.

Entidad: Apoyo

Campos principales:
- id
- causa_id
- usuario
- fecha

Propósito:
Registrar los apoyos que recibe cada causa y llevar un control de la participación.
